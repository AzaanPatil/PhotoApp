# Photo Tagging Feature - User Guide

## Getting Started with Photo Tags

### What is Photo Tagging?
Photo tagging allows you to mark rectangular regions on photos and identify which people are in those regions. It's a great way to organize and identify people in your photos!

---

## Step-by-Step: Creating Your First Tag

### Step 1: Open a Photo
1. Log into your account
2. Navigate to the Photos section
3. Click on any photo to view it
4. The photo should display with a tag interface ready

### Step 2: Select a Region
1. **Position your cursor** over the photo where you want to tag someone
2. **Click and hold** the mouse button
3. **Drag to create a rectangle** around the person's face or body
   - Drag from top-left to bottom-right (diagonal drag)
   - The rectangle will show in **blue** as you drag
   - Keep dragging to make the selection bigger

### Step 3: Complete the Selection
1. **Release the mouse button** when you've selected the region
2. The blue rectangle will freeze in place
3. A **user selection dropdown** will appear below the photo

### Step 4: Select the Person
1. **Click the dropdown** to see the list of available users
2. **Scroll through the list** if there are many users
3. **Select the person's name** you want to tag
   - Look for their name: "First Name Last Name"
   - The name will appear selected in the dropdown

### Step 5: Create the Tag
1. **Review your selection**
   - Check that the rectangle covers the right area
   - Check that you've selected the correct person
2. **Click the "Create Tag" button**
   - Button will be green and clickable
   - Or click **"Cancel"** to start over

### Step 6: Tag Created!
1. The **blue rectangle becomes green**
2. The tag is now permanent on the photo
3. The dropdown disappears
4. You can now hover over the green tag to see the person's name

---

## Using Your Tags

### Viewing Tagged People
1. **Move your mouse** over any green rectangle on the photo
2. A **small tooltip appears** above the tag showing:
   - The person's first and last name
   - A "Remove" button (if you created the tag)
3. **Move your mouse away** to hide the tooltip

### Deleting a Tag
1. **Hover over the green rectangle** you want to delete
2. The **tooltip appears** with the person's name
3. **Look for the "Remove" button** (only visible if you created the tag)
4. **Click "Remove"** to delete the tag
5. The green rectangle disappears
6. The tag is permanently deleted from the photo

### Viewing Other People's Tags
1. **Hover over a green tag** created by someone else
2. You'll see the **person's name** in the tooltip
3. You **cannot delete tags** created by other people
4. Only the person who created the tag can delete it

## Tips & Tricks

### Making Good Tag Selections

✅ **DO This:**
- Select a clear rectangular region around the person
- Include the person's face if visible
- Keep the rectangle reasonably sized (not too tiny)
- Select the torso area if face isn't visible

❌ **DON'T Do This:**
- Make selections too small (system requires minimum size)
- Drag selections that don't contain the person
- Try to tag people who aren't in the selection area

### Tag Placement

**For Face Photos:**
- Draw a rectangle around the face
- Include from forehead to chin
- Include from cheek to cheek

**For Full Body Photos:**
- Draw a rectangle around the torso
- Include shoulders and middle
- Don't need to include legs

**For Group Photos:**
- Create separate tags for each person
- Use non-overlapping rectangles
- Label each person individually

### Managing Multiple Tags
1. You can add **many tags to one photo**
2. Each tag is **independent**
3. Different people can be **tagged in the same photo**
4. Tags at different locations will have **separate rectangles**

## Common Scenarios

### Scenario 1: Tag Someone in a Group Photo
1. Find the group photo in your collection
2. Draw rectangle around first person
3. Select their name from dropdown
4. Click "Create Tag"
5. Green rectangle appears
6. Repeat for other people in the photo

### Scenario 2: Fix a Mistagged Person
1. Hover over the incorrect tag
2. Click "Remove" to delete it
3. Draw a new rectangle in the correct location
4. Select the correct person's name
5. Click "Create Tag"

### Scenario 3: Tag Your Friend in a Photo
1. Open a photo showing your friend
2. Draw a rectangle around your friend
3. Look for their name in the dropdown
4. Select their name
5. Click "Create Tag"
6. Your friend now sees they're tagged in your photo

### Scenario 4: View All Your Tags
1. Open a photo
2. Look for all green rectangles
3. Hover over each to see who's tagged
4. You can see all tagged people at once

## Troubleshooting

### Problem: Selection disappears when I release mouse
**Solution**: The selection was too small. The system requires a minimum size (at least 1% of the image). Try making a bigger rectangle.

### Problem: Can't see "Remove" button on tag
**Solution**: Only the person who created the tag can delete it. You can delete tags you created, but not tags created by other people.

### Problem: Dropdown doesn't appear after selection
**Solution**: 
- Make sure your selection is large enough
- Wait a moment for the interface to respond
- Try refreshing the page and trying again

### Problem: "Create Tag" button is gray/disabled
**Solution**: You must select a person from the dropdown before you can create a tag. Click the dropdown and select someone.

### Problem: Can't click on the dropdown
**Solution**:
- Make sure you completed a valid selection (blue rectangle)
- Try clicking directly on the dropdown arrow
- Check that you have at least one user in the system

### Problem: Tag rectangles look wrong after resizing browser
**Solution**: This is normal! Tags automatically adjust to match the image size. If they look off, refresh the page.

## Privacy & Permissions

### Who Can See My Tags?
- **Public photos**: Everyone can see the tags
- **Private photos**: Only you can see the tags
- **Shared photos**: Only people you shared with can see the tags

### Who Can Delete My Tags?
- **You can delete**: Tags that you created
- **You cannot delete**: Tags created by other people
- **Only creator can delete**: Each tag can only be removed by whoever created it

### Photo Sharing & Tags
- Tags **follow the photo's privacy settings**
- If you make a photo private, all tags become private
- If you share a photo, tagged people are visible to those who can see it
- If you unshare a photo, tags become private again

## Frequently Asked Questions

**Q: Can I edit a tag after creating it?**
A: Not currently. Delete the tag and create a new one if you need to change it.

**Q: Can the same person be tagged twice in one photo?**
A: Yes! You can tag the same person in multiple places on the photo.

**Q: What happens if I delete my photo?**
A: All tags on that photo are deleted too.

**Q: Can tagged people see that they're tagged?**
A: In the current version, they would see it if they view your photos. Future versions may include notifications.

**Q: Can I tag people who aren't registered users?**
A: No, you can only tag people who have accounts in the system.

**Q: What if I tag someone by mistake?**
A: Just hover over the tag and click "Remove" to delete it immediately.

**Q: How many tags can one photo have?**
A: Unlimited! Add as many tags as you need.

**Q: Do tags stay if I move or rename the photo?**
A: Yes, tags stay with the photo no matter what.

**Q: Can I see all photos where I'm tagged?**
A: Not currently. You would need to visit each person's photos to see.

## Best Practices

### Organizing Photos with Tags
1. **Be consistent**: Use the same tagging style for all photos
2. **Be thorough**: Tag all visible people in group photos
3. **Be accurate**: Only tag people you can clearly identify
4. **Keep updated**: Go back and tag photos regularly

### Tag Naming & Selection
1. **Use full names**: Include both first and last names
2. **Spell correctly**: Avoid misspelled name selections
3. **Current users only**: Only tag active users in the system
4. **Clear selections**: Make sure the rectangle is clear and visible

### Photo Organization
1. **Tag similar photos**: Tag related pictures at the same time
2. **Review before tagging**: Look at the photo carefully before selecting
3. **Use consistent regions**: Try to select faces/bodies consistently
4. **Clean up mistakes**: Remove incorrect tags promptly

## Tips for Different Photo Types

### Portrait Photos
- Select just the face region
- Center the rectangle on the face
- Make it large enough to be clear

### Landscape Photos
- Select the person's full body area
- Include torso and shoulders
- Can be smaller relative to image

### Group Photos
- Create separate tags for each person
- Use non-overlapping rectangles
- Label everyone who's visible

### Action Photos
- Select the person in action
- Include the full body if possible
- Make rectangle clear and visible

### Outdoor Photos
- Select the person clearly
- Avoid background clutter in selection
- Make sure person is distinct
